快速开始

1

安装 Skill

Skill 是一个 Markdown 文件，教会你的 AI Agent 如何使用 Show。一条命令即可安装到 Claude Code、Codex、Cursor 等支持的 Agent 中。

npx skills add polunzh/show
2

说 "deploy to show"

你的 Agent 会找到构建产物，打包、通过 curl 上传，然后返回在线链接。无需安装其他任何东西。
