Get started

1

Add the skill

Download show-deploy.md into your agent's skills directory, and set two environment variables.

# Claude Code example
mkdir -p .claude/skills && curl -sL https://raw.githubusercontent.com/polunzh/show/master/skills/show-deploy.md -o .claude/skills/show-deploy.md
# Set credentials (add to your shell profile)
export SHOW_API_URL=https://your-instance.workers.dev
export SHOW_TOKEN=your-deploy-token
2

Say "deploy to show"

Your Agent finds the build output, packs it, uploads it via curl, and returns a live URL. Nothing else to install.
