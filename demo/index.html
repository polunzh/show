One Command

Deploy any static directory with show deploy ./dist. Works from any terminal or AI Agent.

48-Hour Expiry

Every deployment auto-expires. No orphaned previews, no forgotten infrastructure, no surprise bills.

Secure by Default

Instance-level deploy tokens. File type validation. Path traversal protection. No anonymous uploads.

SPA Support

Static multi-page sites work out of the box. Add --mode spa for client-side routing fallback.

Self-Hostable

Run on your own Cloudflare account. One setup command creates everything you need.

Zero Cost

Runs entirely within Cloudflare's free tier. Workers, R2, KV — all within free limits.

Install

git clone https://github.com/polunzh/show.git cd show && vp install node scripts/setup.mjs

Deploy

show deploy ./dist --name my-site

Manage

show list show inspect <id>
